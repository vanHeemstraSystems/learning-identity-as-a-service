# Learning Identity as a Service

## Cloud IAM & Identity as a Service (IDaaS)
CISSP Domain: Domain 2 - Asset Security, Domain 5 - IAM

### Learning Objectives:
	•	Master cloud-native identity services
	•	Understand multi-cloud IAM challenges
	•	Learn IDaaS solution architectures
  
### Study Topics:
	•	AWS IAM, Azure AD, Google Cloud Identity
	•	Cloud access management patterns
	•	Identity as a Service (IDaaS) platforms
	•	Multi-cloud identity governance
	•	Cloud-to-on-premises identity bridging
  
### Assignment:
Compare and contrast IAM capabilities across AWS, Azure, and Google Cloud. Create a multi-cloud identity strategy document addressing governance, federation, and security concerns. Implement a hybrid cloud IAM scenario using at least two cloud providers.
